# ねむログ 🌙

アラームをセットした瞬間から睡眠を記録する、iPhone向けのWebアプリです。

- 起きる時刻を入れて「おやすみ」→ iPhoneの時計アプリにアラームを自動セット（ショートカット経由）
- 朝アプリを開いて「起きた」をタップ → 睡眠時間を記録
- 直近7日の睡眠時間グラフ、平均睡眠時間、目標達成日数、平均起床時刻
- 記録は端末内だけに保存（サーバーには送信しません）。バックアップ／復元機能あり

## 使い方
1. SafariでこのサイトをひらきSafariの共有ボタン →「ホーム画面に追加」
2. アプリ内の「時計アプリ連携の初期設定」でショートカットを追加
3. 夜「おやすみ」、朝「起きた」

## ファイル
- `index.html` … アプリ本体（1ファイル完結）
- `manifest.webmanifest` … ホーム画面追加用の設定
- `sw.js` … オフラインでも開けるようにするためのService Worker
